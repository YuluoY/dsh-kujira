# 使用说明

[简体中文](USAGE.md) · [English](USAGE.en.md)

### 峰谷调度如何工作

在 **设置 → 全局会话调度 → 紧急避险** 中打开。默认关闭，偏好在宿主持久保存。

| 时机 | 行为 |
|---|---|
| 峰价 | 拦截全局 `agent/pre-step` 与 `agent/request`，阻止下一步骤继续执行；主代理和子代理均适用。 |
| 谷价 | 放行等待中的原始 continuation，继续原会话，不发送伪造的“继续”提示词。 |
| 用户手动取消 | 保留取消结果，不会在谷价复活已取消任务。 |
| 关闭调度 | 立即释放调度等待中的步骤。 |

已经发出的模型请求或正在执行的工具会完成，然后暂停；这不是撤销请求，也不能追回已经发生的费用。范围为**同一 DSH 服务进程**，不跨机器控制独立 DSH 实例。峰谷时段取当前计价配置与其时区，不以界面语言推断。

本地预览没有连接真实 DSH，因此会标记为预览；正式安装使用真实钩子。宿主缺少必要能力时会显示不可用，而不是假装暂停成功。

### 金额与补给

`total_balance` 是可用余额，`topped_up_balance` 是剩余充值余额，`granted_balance` 是赠金余额；并非历史充值总额。切换国家只改变格式，**不转换官方账户币种**。会话费用属于依据可核对用量与价格计算的估算，不是官方账单。

谷价每累计 ¥0.10 可核对 DeepSeek 用量预估费用获得一次补给，峰价每 ¥0.05 一次，即同等消费金额获得双倍补给。实际费用不会乘以补给倍率。每五次包含小鱼干×2、摸头／陪玩／舒展各×1，顺序随机。互动共用冷却时间；无限模式不扣库存。预览用量不会产生真实补给。


## 动效与补给

气泡默认停留 5 秒；重新悬浮人物可再次查看。键盘主动聚焦查看不受自动收起打断。

新主会话或子代理首次开始执行时播放吃 Token 动作，读取历史会话不会触发。两种互动模式都按已结算的 DeepSeek 用量费用获得补给。无限模式只增加库存，不因互动扣减；关闭后显示实际数量。新增补给以同一套 SVG 图标依次浮出，短时间同类掉落会合并数量，重载页面不会重播历史奖励。

紧急避险对开启时已经运行的会话也有效。正在请求模型或执行工具的会话显示为“等待安全暂停”，到请求或步骤边界后转为“已暂停”。已发出的请求或工具操作不能撤销，不采用强制中断后重新提交任务的方式伪装为原地续跑。

功能菜单的按钮圆角可在设置中从 0%（正方形）调到 50%（圆形）。悬浮动作完整播放后恢复当前任务状态，快速经过多个按钮只保留最后一个仍在悬浮的动作。峰价获得的小鱼干会散落在人物脚边，最多同时显示 12 条，多余数量合并进奖励提示；几秒后自动收起。静态陪伴和专注模式不播放散落动画。

峰谷规则以北京时间为准：周一至周五 09:00–12:00、14:00–18:00 为峰价，周末全天谷价。下次切换时间转换为设备当地时间显示。详见 [DeepSeek 官方价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)。

## 任务概览与记账

任务进展用于快速查看状态、目标、计划和结果。子代理按待处理、执行中、已结束排序；文件和工具记录按需展开。面板内可查看 Markdown 结果，仅在宿主提供相应能力时显示文件和子代理入口；不再提供无法精确定位的步骤跳转。

补给按已结算的独立用量记录累计。暂停、刷新、重复事件、跨峰谷时钟变化和历史价格刷新都不会产生新补给。中断时迟到的真实用量仍会结算；其他主会话或子代理继续使用时也会继续累计。所有执行结束或暂停后，清空未播放的奖励动画，库存保留。升级不追溯重发历史补给。

## 会话金额显示

在设置 → 用量与隐私中调整“金额小数位”，支持 0–6 位，默认 4 位。设置同时用于底栏与费用详情，不改变用量计算或补给累计。金额变化时仅更新的数字上下滚动；首次加载、切换会话、切换地区或精度时直接显示，减少动态效果或专注模式下不滚动。费用详情先显示合计，再显示谷价和峰价分项；底栏悬浮仅提示下次切换时间。

## 任务详情分类

任务概览保持可见，下方通过协作、计划、文件、记录四类 tabs 切换。没有数据的类别不显示。每类保留滚动位置和已展开的列表数量；方向键及 Home/End 可切换。任务结果继续在面板内查看。

默认安装不会额外调用模型，但会有本机资源开销。参见[性能、模型用量与测量方法](PERFORMANCE.md)。

任务分类按以下范围展示：协作包含跨轮次仍在执行或等待处理的子代理，以及本轮启动或完成的子代理；计划保留本会话最近一次 `todo/write`，跨轮时标为“最近计划”，新列表（包括空列表）会替换旧列表；文件保留本会话最近 20 个已确认修改的文件；记录展示当前轮的工具操作。继承自其他会话的日志不计入这些分类。

PTC 模式读取 `tool/ptc-dispatch-start` / `tool/ptc-dispatch`，显示 `run_code` 内实际执行的操作，并保留外层错误。文件分类仅收录成功的 `write`、`edit`、`write_file`、`edit_file` 与 `str_replace_editor` 写入操作；读取、失败操作、未知工具及 Bash 输出不作为文件修改证据。无数据的分类不显示。

文件显示相对会话工作目录的路径，项目外文件保留完整路径；打开文件始终使用原路径。计划、文件和消息摘要最多两行，截断后可悬浮或用键盘聚焦查看全文，长提示支持滚动。执行中的计划与操作使用加载图标，读屏仍可获得状态。

顶部显示最近的公开消息，点击可定位到原文。“对话”分类提供每页 30 条的消息索引，可继续读取更早消息。定位使用消息身份和事件位置，必要时通过宿主加载历史；切换会话或关闭面板会取消后续定位。不同版本宿主缺少相应能力时会保留内容并提示，不会猜测相似文字的落点。

计划完成数和进度条同一行展示，数据来自真实 `todo/write`，不是按时间估算。面板打开期间约每 1.5 秒刷新，隐藏页面暂停轮询。更新保留所选分类、已加载的消息页和分类滚动位置。
