# 紧急避险：行为与验证边界

紧急避险在**同一个 DSH 服务进程内**拦住原任务的下一步/下一次模型请求。谷价到来时释放正在等待的原 continuation，不重新提交提示词、不重新创建任务、不重放已经完成的工具调用。

## 使用

在「设置 → 全局会话调度 → 紧急避险」开启；默认关闭。运行中的请求和工具会先完成，随后在安全边界等待。暂停中的任务在输入框显示暂停标记；不需要点击它来等候自动恢复。

输入框原来的停止按钮只改变暂停时的图标和可访问说明，原停止操作仍然有效：**点击停止会取消任务及其自动续跑**。有待发送文字时不修改发送/追加消息按钮。适配器只识别当前会话 composer 内的已核对停止图标；宿主结构变化时保留原按钮，并通过插槽显示暂停说明。识别成功时不额外占用工具栏宽度。

## 输入框视觉适配依据

根据用户提供的真实输入框截图，进一步对照 GitHub `deepseek-ai/deepseek-harness` 提交 `c291e7961a515f6d7af9304e7fd1d257929aef26` 的 [InputBar.module.css](https://github.com/deepseek-ai/deepseek-harness/blob/c291e7961a515f6d7af9304e7fd1d257929aef26/packages/client/ui-conversation/src/client/skeleton/InputBar.module.css#L355) 与 [InputBar.tsx](https://github.com/deepseek-ai/deepseek-harness/blob/c291e7961a515f6d7af9304e7fd1d257929aef26/packages/client/ui-conversation/src/client/skeleton/InputBar.tsx#L525)，并与本机 0.1.5-rc.1 交叉核对：

## 可保证的范围

在配置有效、调度插件与宿主仍运行、任务没有被取消且仍停留在调度 gate 的条件下：

- 每个等待者都记录自己的取消信号与原 Promise；谷价切换会释放全部等待者。存在等待者时计时器保持进程活性，全部释放后恢复为空闲计时器。
- 同一任务的多个 gate 会分别释放，但不会重复调用任何一个 gate 的 next。
- 主任务、子任务使用同样的全局 hooks；session.header.id、session.id、agent.id 都能关联暂停状态。
- 谷价正常恢复、关闭开关、宿主服务卸载释放等待，不通过额外提示词继续。
- 用户主动停止、任务自身失败或外部取消后，等待者从集合和身份索引删除，下一次谷价不会复活它。
- 如果谷价刚放行又立刻变回峰价，continuation 重新检查时段，仍在峰价时继续等待。
- 配置保存失败不改变已有开关；客户端无法确认保存结果时明确等待重新同步，不声称服务端一定没改。

## 不属于这个机制的保证

- **不中断已经在执行的模型请求/工具**。价格切换时，正在执行的一步可能跨过边界；本功能不能追溯取消费用，也不负责改变服务商如何计费。
- **不跨进程恢复执行栈**。这里只持久化开关，等待中的 Promise 不写入磁盘。DSH 退出、重启、崩溃后，旧等待栈不存在；不能承诺在下一个谷价重启这些任务。
- 不跨不同 DSH 服务、远端进程或已脱离本服务的任务；也不绕过宿主的取消、错误、预算和能力限制。
- 浏览器关闭不等于服务退出；只要服务及原任务仍在运行，服务器的调度计时器可以继续释放任务。浏览器重新连接后重新读取状态。
- 使用后端配置的北京时间周一至周五（中国放假日除外，周末补班仍为谷价）及整点 peakHours。配置热变更或系统时间回退会使缓存失效。空时段/空工作日代表没有峰价；非法规则会明确报错，已启用时保持挂起直到规则修复或用户关闭开关。

## 审查发现与修复

| 问题 | 处理 |
| --- | --- |
| 只使用部分身份字段，暂停统计/界面与实际 gate 可能对应不上 | 统一身份别名；暂停计数使用 Map，支持同任务多个 gate |
| 每次快照重复扫描未来 7 天来计算切换时间 | 缓存下一边界；到期、规则变化或时钟回退时重新计算 |
| 客户端只知道任务执行状态，不知道价格暂停状态 | 在现有 activity 响应中加入 scheduling；ETag 包括暂停、等待暂停和恢复时间 |
| 没有单独覆盖停止按钮的公开插槽 | 使用 conversation.input.right 加受控适配，保留原 onClick；不替换整个输入框 |
| 预览活动接口绕过了真实暂停投影 | 删除重复的预览活动接口，走真实插件路由 |
| 非法时段配置可能使计时器抛错 | 验证规则并显示 unknown 状态；不误判为谷价放行 |

## 验证证据

本次检查了本机安装的 `@deepseek-ai/dsh-agent`、`dsh-agent-loop`、`dsh-client-ui-conversation` **0.1.5-rc.1** 的源码与类型契约：

- `agent/pre-step` 使用本轮取消信号；它是 await 的 waterfall，返回后仍检查 abort。
- `agent/request` 在准备模型调用前 await waterfall，返回后再次检查 abort。
- conversation 的 `conversation.input.right` 为 session scope；composer 有 `data-composer-card`；停止按钮的原处理函数调用宿主 stop。

`tools/test-scheduler.mjs` 共 16 项：默认值、持久化、全部恢复、用户取消、保存失败、恢复旧设置、服务卸载、北京时间边界、跨界准备、拒绝/异常、200 个并发 gate、多身份、多次峰谷切换、单独取消子任务、规则变化/时钟回退、非法规则与等待期间的进程保活。

本地无模型预览通过真实 scheduler gate 与 HTTP activity 路由验证：峰价进入暂停、谷价释放与按钮复原；用户点击停止后再次进入谷价，续跑计数为 0。未在真实付费任务上跨时段运行，因此不把这些测试写成对所有宿主版本或故障情形的绝对保证。

本地预览「状态预览」提供「峰价暂停（右三角）」与「谷价恢复」，通过隔离预览的真实调度 gate 切换按钮状态，不需要发起模型请求。右三角仅表示当前暂停状态，原按钮仍保留停止任务处理函数。

## 接管清单与交互边界（2026-09-14 复核）

「设置 → 服务 → 全局会话调度」开启后显示接管清单：完整 session ID、已暂停／等待安全暂停、步骤／模型请求边界、父会话 ID，以及宿主可读取的 Goal 状态。清单来自服务端真实等待者与活跃 Agent，不根据当前浏览器打开的页面猜测。界面只在该设置组件挂载时每 5 秒刷新，不额外扫描会话历史，不发起模型调用；连接失败时保留旧结果并显示错误。

| 操作或场景 | 实际行为 |
| --- | --- |
| 打开已有会话、切换父子会话、查看历史 | 不释放调度 gate，也不由插件提交消息；打开历史会话不等于恢复执行 |
| 新建空会话 | 没有执行就没有等待者，不列成已暂停 |
| 峰价时新建并发送消息、在已有会话再次发送 | 新执行一样经过全局 gate；等待者出现后列入清单 |
| 暂停中追加／插入消息 | 保留宿主 next-turn／next-step 队列语义，不替换已领取的消息；要取消旧指令，应先停止原执行 |
| 关闭紧急避险 | 即使仍为峰价也立即释放剩余等待者，可能继续产生费用；不创建新执行或 Goal 授权 |
| 用户停止任务或手动暂停 Goal | 取消信号移除等待者；谷价与关闭开关均不重新拉起它 |
| 主任务在等子代理 | 子代理在自己的 gate 等待，父任务保留原工具等待；放行后原结果回到父任务，不重新派发工具 |
| 父任务取消 | 同进程驱动会把父取消传给子代理；被取消子代理不会在谷价重启 |
| Goal 自动续轮 | 宿主仍保留自己的轮次预留和校验；避险不创建、暂停、恢复或修改 Goal，不消耗额外轮数 |
| Goal 在等待时完成／修订／轮数耗尽 | 尚未获准的新轮次由宿主预留校验和轮数上限拦截；已获准的当前回合遵循宿主规则。人工暂停会取消运行中的 Agent |
| 关闭页面、关闭桌宠、网络断开 | 只要 DSH 服务仍活着，调度继续；界面重连后读取同一份状态 |
| DSH 重启／崩溃、插件卸载 | 开关可持久化，执行栈不能持久化。卸载释放 gate；重启不能承诺恢复旧任务或重新给 Goal 授权 |

范围限定为当前服务进程内经过 `agent/pre-step` / `agent/request` 的 Agent。已在执行的一步、工具内部自主循环、独立子进程／远端 Agent、直接使用 LLM 服务的其他插件（例如标题生成）不等价于下一次 Agent 请求；本功能不是系统级计费断路器。外部工具自身的超时和取消依然有效，不为了等待谷价无限延长它们。

本机核对版本为 **0.1.5-rc.1**，直接阅读并加载安装包 `dsh-agent-loop`、`dsh-goal-round-driver`、`dsh-goal`、`dsh-subagent-in-process-driver`、`dsh-subagent` 的实现。已确认：

- Agent loop 的 `followup/steer` 分别进入 next-turn/next-step；cancel 默认清空 inbox 并中止当前信号；两个 waterfall 返回后均检查 abort。
- Goal driver 在 pre-step 前后检查相同预留；外部 `goal/changed: pause` 会取消运行中的 Agent；session-start 会移除旧的自动续轮授权，轮数用尽由宿主阻塞。
- 子代理通过 `parent.ctx.agents.create({parentAgent: parent, ...})` 创建；同进程运行持有父信号，在父取消后调用 child.cancel，再等待子任务结算。
- 未为验证而暂停、重启或提交本机真实 DSH 任务。

`node tools/test-scheduler.mjs` 包含 20 项无模型回归；`node tools/test-scheduler-harness.mjs` 直接加载本机安装的同版本 Goal/子代理驱动，5 项隔离适配测试验证预留不重播、人工暂停、过期预留／轮数上限、子任务恢复、父取消传播。后者使用假的 Agent/会话存储和真实驱动，不等同于完整运行时端到端测试。非本机环境可通过 `DSH_HARNESS_STORE` 和 `DSH_HARNESS_VERSION` 指定安装仓库和精确版本；无安装包时显式跳过，不报告为已验证。

### 即将接管与分页

开启后，谷价阶段显示「即将接管的会话」：仅列当前运行中的 Agent，状态为 `upcoming`，不计入已暂停或等待安全暂停数量。该清单是当前快照而非未来任务预测；任务提前完成会移出，之后新启动的任务仍经过同一个 gate。未配置未来峰价时段时不列候选。进入峰价后切换为接管清单，并区分实际 gate 等待者与尚未到达安全边界的运行任务。

清单按 session ID 稳定排序，每页最多 3 项；显示总数与页码。峰谷状态切换重置页码，任务移除导致尾页消失时自动回到有效页；翻页只切换本地显示，不重复请求服务或挂载全部行。候选说明放在标题旁的问号提示中。

### 信息层级

每个 session 固定一行：会话／子代理图标、可点击的会话标识、状态图标、信息图标。时钟表示待接管，沙漏表示等待安全暂停，暂停符号表示已暂停；子代理采用分支图标。完整 ID、Goal 和父会话等详情仅在信息图标提示中出现，不再展开多行。图标均有本地化的悬浮、焦点与点击提示。会话标识仍通过 DSH 打开对应 session，保持每页 3 项。

会话／子代理图标点击后复制该行的原始 session ID，提示成功或失败；会话标识文字继续负责打开会话。浏览器使用 Clipboard API，桌面使用受信 IPC 写入系统剪贴板，不读取用户的剪贴板内容。

提示层统一接收鼠标事件；移入浮层、选取文字或返回原图标时取消关闭计时器。离开两者后等待 300ms 再关闭，Escape、外部点击和面板卸载仍可关闭。桌面宿主把已显示提示层的边界计入交互区域，避免鼠标穿透。

### 长 ID 与开关保存修复

设置字段容器和会话列表使用 `minmax(0, 1fr)` 轨道，并允许各层子项收缩。实际 320px 面板中，长 ID 按钮内容宽 318px、可用宽 204px，行宽与滚动宽均为 288px；ID 省略显示，右侧图标和开关仍在可视区域。

调度保存递增客户端读取代次，保存前发起的旧 GET 不得覆盖保存结果。即使宿主暂不支持暂停，已经开启的开关仍允许关闭。隔离加载本机 Goal 驱动确认：Goal 续轮不会将关闭的调度器打开。

2026-09-14 实际服务检查发现开关持久化为 true，但当时处于谷价、无已暂停任务。现有文件不包含操作来源，不能把该值归因于某次 Goal 操作。修复后已通过实际网页开关关闭，并核对 GET 与磁盘均为 false；未停止 Goal 或重启 DSH。

### 会话标题与浮层边缘

会话行显示 Harness `sessionProjections.stateOf(session, "title")` 的当前标题，未生成标题时显示「未命名会话」。调度快照直接读取现有投影，不额外扫描历史或生成标题；session ID 仍是复制与导航的唯一标识。

提示层关闭判断增加指针坐标与当前实际矩形校验（2px 边缘容差），不依赖 `pointerout` 或 `:hover` 单一状态。左右边缘仍在范围内时保持打开；其他会话区域滚动不会关闭浮层，指针停留在浮层内时不因页面滚动销毁。Escape、外部点击、锚点卸载仍可正常关闭。
