# 紧急避险：状态与交互约定

## 执行规则

紧急避险控制同一个 DSH 服务进程里的会话、Goal 续轮和子代理。默认关闭。

| 场景 | 行为 |
| --- | --- |
| 谷价时开启 | 当前任务正常运行，显示即将接管的会话 |
| 进入峰价，或在峰价开启 | 正在执行的请求和工具先完成，在下一次安全边界暂停 |
| 峰价主动发送消息 | 放行该会话及其子代理，其他会话继续避险 |
| 主动创建或恢复 Goal | 宿主能确认是人工操作时，同样放行该任务树 |
| 点击暂停会话的「继续」 | 释放原等待过程，放行该任务树；不重发提示词、不重放工具、不关闭全局开关 |
| 到达下一段峰价 | 上一段的人工放行失效，仍在执行的任务重新受保护 |
| 点击「停止任务」或人工暂停 Goal | 由宿主取消任务；谷价到来或关闭开关都不会重新启动已取消的任务 |
| 谷价到来或关闭开关 | 释放仍然有效的等待任务 |
| 打开历史、切换会话、刷新或重新连接 | 只读取当前状态，不授予执行权限 |

人工发送包括向已暂停的同一会话追加消息：它会放行该会话的原执行过程，消息仍按宿主的 next-turn / next-step 队列处理。Goal 自动续轮、子代理发出的消息和系统上下文不等于人工发送。

人工放行以当前峰价区间和活的 Agent 实例为界。子代理继承本次放行；新建的其他会话、替换后的 Agent、下一段峰价都不会继承旧权限。重新关闭再开启紧急避险，会重新接管当前任务。

## 状态来源

| 状态 | 来源与含义 |
| --- | --- |
| `upcoming` | 谷价时仍在运行、后续有峰价的会话 |
| `pausing` | 峰价运行中的受保护会话，尚未到达安全边界 |
| `paused` | 服务端确实持有该会话的等待过程和取消信号 |
| 人工放行 | 不再计入本段峰价的接管清单；原执行继续 |
| 完成／取消／失败 | 由宿主的执行事件确认；不能仅按峰谷时段推断 |

`agent/pre-step` 与 `agent/request` 共同保护下一次执行。空的 pre-step 允许宿主检查任务是否已经结束，真正的模型请求仍经过 request gate；不把收尾检查当成一个付费步骤无限等待。每个 gate 的 `next` 只调用一次，拒绝和取消结果不重播。

接管清单由真实等待者和活跃 Agent 构成，不扫描历史来猜测任务是否运行。会话标题读取宿主现有投影；身份同时识别 session.header.id、session.id 和 agent.id。

父会话仍在工具内等待子代理时，子代理可以已暂停而父会话尚未到达自己的暂停边界。这是两个真实的执行状态；放行父任务树会同时释放后代，独立放行一个子代理不会放行兄弟或父任务。

## 输入框、Goal 与子代理

- 输入框右侧的三角形现在执行「继续」，不会调用宿主停止处理函数。独立的方形停止按钮用于取消任务。
- 只适配已经核对的宿主停止图标；输入、发送和追加消息按钮仍保持原语义。同一输入框有多个停止控件时，暂停期间只保留一个继续入口和一个明确的停止入口。
- 宿主停止控件无法识别时，通过插件插槽提供明确的继续按钮。
- Goal 在避险暂停时显示暂停图标和峰价暂停说明；原暂停动作位置提供继续入口。此显示是调度状态投影，不修改 Goal 的持久化 phase、revision、activation 或轮数。
- 人工暂停、完成、清除或编辑 Goal 时，宿主的原状态优先。移除适配时恢复插件拥有的属性，不替换 React 管理的图标节点。
- 主会话和侧栏子代理按各自 session ID 读取同一个调度快照，不能借用桌宠“当前会话”的状态。

## 保存与同步

| 内容 | 保存位置 | 页面重连 | 服务重启 |
| --- | --- | --- | --- |
| 全局开关 | `peak-scheduler.json` | 读取服务端 | 恢复已保存开关 |
| 原执行栈、等待者、暂停身份 | DSH 进程内存 | 读取当前等待状态 | 不恢复旧 Promise |
| 本段峰价的人工放行 | 活 Agent 的内存状态 | 保持本次放行 | 不继承旧执行权限 |
| Goal 内容、阶段和轮次 | 宿主 Goal 服务 | 使用宿主投影 | 遵循宿主恢复规则 |

开关先写临时文件，再原子替换，成功后才改变内存状态。保存失败保持原设置，保存队列不会被一次失败破坏。

设置面板、输入框和 Goal 共用调度订阅，串行读取并共享命令状态。命令确认前不乐观切换；保存或继续之前发出的旧 GET 不能覆盖成功响应。断线保留已确认的暂停显示并禁用继续，避免回退成可误触的停止按钮；重连后重新同步。调度操作完成后立即刷新桌宠任务进展，并丢弃操作前发起的旧活动响应。

每次暂停有独立 `pauseId`。继续请求同时携带会话 ID 与该身份，服务端核对后才放行。任务已结束、取消或进入另一轮暂停时，过期请求返回 409，不影响新执行。活动接口的 ETag 包括暂停身份、开关、可用性、价格和人工放行状态。

## 边界

- 已经执行中的模型请求和工具不会被追溯撤销，切价前开始的一步可能跨过价格边界。
- 范围仅限经过这些 Agent hooks 的本进程任务。独立服务、外部工具自己的循环、直接调用模型的其他插件不在此范围。
- 北京时间和中国放假日历决定峰谷，语言和显示币种不改变规则。无效规则显示错误并保持等待，修复规则或关闭开关可解除；不能在价格未知时单独强制继续。
- 浏览器关闭不会停止服务端调度。服务退出或崩溃后不能保存 JavaScript 执行栈，也不会伪造自动恢复。
- 插件卸载或宿主能力移除会释放等待；宿主的预算、人工暂停、取消信号和 Goal 预留校验仍然生效。

## 验证

- `tools/test-scheduler.mjs`：安全边界、空收尾、人工放行、任务树继承、下一段峰价、身份别名、取消、保存失败、加载竞态、并发等待和过期继续请求。
- `tools/test-scheduler-client.mjs`：共享订阅、主／子会话隔离、命令确认、旧响应隔离及断线状态。
- `tools/test-scheduler-http.mjs`：真实 HTTP 暂停和继续、来源校验、过期身份、活动响应与 ETag 一致性。
- `tools/test-scheduler-harness.mjs`：加载本机已安装 Goal 和同进程子代理驱动，在隔离会话中验证预留不重播、人工暂停、轮数限制和父子取消传播。安装包不存在时明确跳过。
- `tools/fixtures/scheduler-ui.html`：在预览服务打开，自动检查继续不取消、Goal 图标、主子界面隔离、断线点击、原控件恢复和发送按钮识别，并保留可操作的样例。

本次核对本机安装的 **0.1.7-rc.2** 源码。浏览器和 HTTP 验证使用隔离预览，不调用付费模型，也不暂停或重启现有真实任务。
