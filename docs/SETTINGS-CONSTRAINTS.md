# 设置输入约束

数字控件区分可编辑草稿和可保存值。清空、输入小数点等中间状态不写入设置；离开空白输入框恢复上次有效值。字母、科学计数法、百分号等内容不能作为数字保存。粘贴超限数值会即时回到边界，整数栏拒绝带非零小数的输入，金额按两位小数归整。支持输入法组合输入结束后的全角数字转换，以及现有本地化数字格式。

| 字段 | 有效值 |
| --- | --- |
| 人物大小 | 120–360px，整数 |
| 不透明度 | 35–100%，整数 |
| 按钮圆角 | 0–50%，整数；50% 即圆形 |
| 每页按钮 | 3–8，整数 |
| 气泡停留 | 1–60 秒，整数 |
| 金额小数位 | 0–6，整数 |
| 预算 | 0–1,000,000 CNY，最多两位小数；0 关闭提醒 |
| 掉落判定额度 | 0.01–100 CNY，最多两位小数 |
| 掉落概率／小鱼干占比 | 0–100%，整数 |
| 最少／最多件数 | 1–20，整数；最少不得超过最多，两框动态约束 |
| 自动检查间隔 | 6／12／24／72 小时 |
| 辅助模型 ID | `deepseek-` 后接 1–70 位小写字母、数字或连字符 |
| 国家、主题、动画及其他选项 | 只接受各下拉框声明的选项 |
| 开关 | 布尔值，拒绝用字符串或数字代替 |
| 称呼 | 最多 24 个字素，清除控制字符 |
| 城市 | 最多 80 个字符，去除首尾空白 |
| 本机 DSH 地址 | 最多 200 字符，仅 HTTP 的 127.0.0.1／localhost／[::1]；无用户信息、额外路径、查询或片段；端口不能为 0 |
| DSH 配置名称 | 1–64 位；字母或数字开头，其后仅字母、数字、下划线、连字符 |
| DSH 程序 | 通过文件选择器选择，输入框只读；宿主限制 1024 字符并拒绝换行、空字符 |

外观设置的读取和更新共用 `PREFERENCE_NUMBERS` 与 `normalizePreferences`；非法历史数字回退默认值或截到边界，合法数值在下一次保存时规范化落盘。控件与存储使用相同范围。

库存服务已有完整掉落规则校验，继续拒绝非法类型、越界值、超过两位小数或倒置的数量范围。桌面保存使用严格校验，旧配置读取保留容错。实时同步配置整体校验后串行保存，非法请求返回 400，保存失败保留原状态；不部分应用一个非法请求中的其他字段。

验证包括控件输入／粘贴／IME／空值／步长、非法持久化配置、API 参数类型和范围，以及实际预览输入测试。测试不修改正式 DSH 的掉落参数、库存或运行任务。
